## 👋 Sobre mim

Ei, tudo certo? Prazer, sou o Edu.

Sou Desenvolvedor Full Stack Jr., formado em Técnico em Informática para Internet pelo IFRN.

Desenvolvo projetos próprios utilizando principalmente **React**, **Next.js**, **Django** e **Django REST Framework**, buscando unir uma boa experiência de usuário com código organizado e soluções que realmente resolvam problemas.

Gosto de aprender construindo. Cada projeto é uma oportunidade para colocar conceitos em prática, experimentar novas tecnologias e evoluir como desenvolvedor.

Atualmente, estou em busca da minha primeira oportunidade profissional como Desenvolvedor de Software.
