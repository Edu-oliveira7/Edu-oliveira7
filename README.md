## 👤 Sobre mim

Sou Desenvolvedor Web Full Stack Jr. apaixonado por criar aplicações modernas, escaláveis e focadas na experiência do usuário. Minha principal stack é Python, Django, Django REST Framework, React e Next.js. Gosto de transformar ideias em produtos reais, sempre buscando evoluir como desenvolvedor de software por meio de projetos práticos, boas práticas de desenvolvimento e aprendizado contínuo.
